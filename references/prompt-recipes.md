# 紧凑提示词编译器

## 为什么要短

图片编辑模型需要明确的变化方向，而不是一份审计报告。身份、物体、尺寸和风险分析可以在内部完成；真正发送给模型的提示只保留一个主光逻辑、一个曝光意图、一个肤质尺度、一个色温关系和最多一个氛围效果。

长提示常见副作用：

- “保持不变”重复过多，模型直接复制原图；
- 多套主光同时出现，形成无来源高光和双重阴影；
- “毛孔、黑头、卡粉、颗粒、粗粝”同时堆叠，皮肤变脏；
- 负向词过多，目标光影被抵消；
- 逐项描述五官，反而诱发重新画脸。

## 固定四行

图片工具、`prompt-only`、`invocation-handoff` 和 `prompt-handoff` 都使用同一结构：

```text
编辑：对输入人像重照明；保持同一人物、原五官结构、表情、姿势、镜头、构图与原画幅。
光影：{一个 L 主光句} {曝光意图与暗部策略} {零个或一个 A 氛围句} {一个 T 色温关系}。
肤质：{一个 S 皮肤句}。
限制：不换脸、不磨皮、不颗粒化、不脏化、不重绘背景；目标光影在正常观看下清楚可辨。
```

长度规则：

- 默认 120–220 个中文字符；
- 有文字、商品或复杂背景时最多 320 个中文字符；
- 每行只承担一个职责；
- 身份锁定只出现一次；
- 保护物只点名最高风险的 1–3 类，例如“书页文字、电脑、灯具”；
- 不把 L/S/T/A 编号、内部置信度、验收步骤或后端说明写入正文。

## 编译顺序

1. 从 [配方表](lighting-skin-color-temperature-recipes.md) 选一个 `L`、一个 `S`、一个 `T` 和零个或一个 `A`；
2. 删除配方解释，只取每张卡的“提示句”；
3. 把主光方向写成可见动作，例如“左前方柔窗光塑造左明右暗的宽缓渐变”；
4. 明确曝光意图，再决定是否需要 Fill；剪影、低调和高光优先曝光可以写“无正面补光”；
5. 把阴影深度、高光处理和背景响应并入同一句；
6. 皮肤只写尺度相符的微纹理，不列举一整套瑕疵；
7. 最后保留 4–6 个最高风险限制，删掉同义词。

### A6 强制编译

配方含 `A6` 时，不按普通氛围追加一句，而是覆盖人物受光与肤质句：

1. 固定 `silhouette` 曝光，把主光落在人物后方或明亮背景上；
2. 删除 L 中照亮人物正面/侧面的内容，以及全部 Fill、catchlight 和人物内部高光；
3. 光影行明确“整个人物内部连续全黑，只保留原外轮廓、比例和姿态”；
4. 肤质行改为“剪影内部不显示肤色、五官、毛孔、唇纹、发丝或衣物细节”，不使用 S 的普通纹理句；
5. T 只描述背景与背后亮源，不给黑色人物内部染色。

## 可观察目标

用一个画面结果替代“高级、通透、电影感”等空泛词：

- 逆光：`夕阳高光与发丝轮廓保留，背光面按曝光意图成为深暗、局部剪影或低幅补亮`；
- 窗光：`左明右暗的宽缓渐变同时出现在人物与墙面`；
- 杂志：`短而柔的鼻影、单一眼神光、面颊层次清楚`；
- 暗调：`光带穿过眼鼻颊，带外区域深暗且轮廓干净，可接近黑色`；
- 黄金时刻：`暖色侧逆光勾勒发丝，面部背光侧形成自然深影或局部剪影`；
- 霓虹：`青色轮廓与洋红侧光方向分明，未受光区域自然压暗`。
- A6 全黑剪影：`人物位于亮背景或背后主光之前，脸、头发、皮肤、衣物与身体内部全部连续全黑，只以原外轮廓和姿态可辨`。

## 六个可直接使用的短提示

### 经典时尚杂志

```text
编辑：重照明输入人像；保持同一人物、五官结构、表情、姿势、构图与原画幅。
光影：左前上方大型柔光形成克制伦勃朗光，轻微正面补光保留眼窝，一侧面颊阴影干净深柔，仅保留一处同源眼神光；背景极简低对比。
肤质：白皙健康、低对比真实微纹理，保留原有唇纹与眼周层次，可选全画面极轻细腻胶片颗粒。
限制：不换脸、不磨皮、不颗粒化皮肤、不加深皱褶、不重绘背景。
```

### 电影低调冷暖

```text
编辑：重照明输入人像；保持同一人物、表情、姿势、镜头与原构图。
光影：暖色侧主光塑造强烈明暗面，采用低调曝光、无正面补光，背光侧可接近黑色；冷蓝环境光只留在背景与轮廓，轻微体积微尘沿主光方向可见。
肤质：干净连续的自然肤色与低对比微纹理，不靠深眼袋或法令纹制造戏剧感。
限制：不换脸、不脏灰、不双重阴影、不颗粒化、不全局橙青滤镜。
```

### 黄金时刻逆光

```text
编辑：重照明输入人像；保持同一人物、五官、表情、姿势、背景结构与原画幅。
光影：暖色夕阳从侧后方照亮发丝与肩部，按夕阳高光曝光且无正面补光；面部背光侧自然压暗成局部剪影，受光边缘可轻微溢出，背景同步接受斜射暖光与长阴影。
肤质：只在有效受光区域呈现白皙健康、低对比真实微纹理；剪影区域不强行提亮细节。
限制：不换脸、不平均提亮、不橙色滤镜、不抠图白边、不塑料皮。
```

### 赛博朋克霓虹

```text
编辑：重照明输入人像；保持同一人物、五官结构、表情、姿势、服装与原构图。
光影：青色轮廓光来自一侧，洋红主光来自另一侧，采用低调曝光且无白色正面补光；未受光面自然深暗，城市 Bokeh 只在背景离焦区。
肤质：保留真实皮肤反射与低对比微纹理，不做油亮塑料表面。
限制：不换脸、不高饱和染满皮肤、不双重鼻影、不覆盖眼睛、不重绘服装。
```

### 柔和窗边自然光

```text
编辑：重照明输入人像；保持同一人物、五官、表情、姿势、场景物体、构图与原画幅。
光影：左前上方柔和窗光形成宽缓左明右暗，微弱室内补光保留暗侧；人物、衣物与墙面呈同方向亮度衰减，可选一层柔软窗影。
肤质：干净健康、低对比自然微纹理，保留原有唇纹和眼周层次。
限制：不换脸、不矩形贴纸光斑、不脏灰阴影、不磨皮、不重绘场景。
```

### 主体全黑逆光剪影

```text
编辑：重照明输入人像；保持原人物的头发与头部外轮廓、头身比例、姿态、镜头、构图与画幅。
光影：把主光置于人物后方并按亮背景曝光，取消全部正面/侧面补光、眼神光与人物内部受光；脸、头发、皮肤、衣物和身体内部连续全黑，只以清楚外轮廓形成逆光剪影，背景正常响应背后光源。
肤质：剪影内部不显示肤色、五官、毛孔、唇纹、发丝、衣纹或饰品细节。
限制：不改变人物外轮廓、比例和姿态，不出现灰色填充、局部面光、白色抠图边或内部残留细节。
```

## 按面部尺度替换肤质句

### S0：面部小于 256 px

```text
肤质：保持干净连续肤色与自然反射，去除塑料般均匀感，不新增可见毛孔、黑头、绒毛或细纹。
```

### S1：面部 256–511 px

```text
肤质：白皙健康、低对比不规则微纹理，保留原有唇纹、眼周层次与克制额头反光；不新增黑点、粉屑或色斑。
```

### S2：面部至少 512 px

```text
肤质：干净连续的真实相机微纹理，脸颊孔理柔和、鼻头略清晰，保留原有唇纹、眼下浅纹、细绒毛与标志；不新增污点或粗糙颗粒。
```

## 失败时只替换一句

不要在旧提示后追加更多限制。根据失败类型替换对应行：

| 失败 | 替换方式 |
| --- | --- |
| 近乎原图 | 把光影行改成明确方向、落点和正常观看可见的结果，删除“轻微、尽量、最小变化” |
| 改脸 | 缩短编辑行，只保留“同一人物、原五官结构、表情与构图”，不描述眼睛、鼻子、嘴唇外形 |
| 皮肤变脏 | 用 `干净连续肤色 + 低对比反射微纹理` 替换毛孔/颗粒/瑕疵清单 |
| 光线太杂 | 只留一个 Key、一个低强度 Fill 和一个背景响应，删除第二主光与多余氛围 |
| 假光斑 | 指定光斑的来源、落点和边缘软硬，并要求跨人物与邻近表面连续响应 |
| 非预期暗部丢失 | 仅当选定曝光本应保留暗部时增加 `subtle fill light`；剪影、低调或高光优先曝光不补亮 |
| A6 仍见人物内部细节 | 删除普通 S 句和 L 的人物受光句，改为 `整个人物内部连续全黑，无 Fill、catchlight、肤色、发丝高光或衣纹` |

## 提示词禁区

删除这些容易导致 no-op、改脸或脏化的表达：

- 完全保持不变、最小像素变化、尽可能不改变、所有细节逐项锁定；
- 完美对称、五官精致化、黄金比例、网红脸、无瑕瓷肌；
- 超高清毛孔、大片黑头、粗粝原生肌、强颗粒感、强局部清晰度；
- 深邃眼下、强化法令纹、加深鼻翼沟、HDR 雕刻；
- 同时出现柔窗光、硬光束、伦勃朗光、霓虹、夕阳与体积光；
- 无论光型都要求面部完整可见、高光不过曝、暗部全部有细节；
- 选择 A6 后仍要求真实肤质可见、眼神光、面部补光、发丝高光或衣物细节；
- 只有“高级感、电影感、氛围拉满”而没有光源方向与落点。
