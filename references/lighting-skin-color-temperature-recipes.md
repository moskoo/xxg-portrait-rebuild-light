# 光影、皮肤、色温与氛围配方

## 选择协议

每次只选择：

```text
一个 L 主光 + 一个 S 皮肤 + 一个 T 色温 + 零个或一个 A 氛围
```

顺序是 `Key → Exposure → Fill → Shadow → Subject → Background → Atmosphere`。配方编号仅用于内部记录，真正交给图片模型时只取每张卡的一句“提示句”。

固定原则：

- 主光必须有方向、软硬和主体落点；
- 先决定曝光意图，再决定是否使用 Fill；Fill 可以为零，不能默认补亮所有暗部；
- 阴影的深浅与边缘必须符合主光面积和距离；
- 背景与人物响应同一组光源；
- 氛围最多一种，且必须服从主光；
- 皮肤先干净健康，再在合理尺度出现低对比微纹理。

唯一例外是 `A6`：它是主体全黑剪影的强制覆盖项。选择 A6 后，曝光意图固定为 `silhouette`，人物受光与肤质可见性规则由 A6 接管。

光源物理关系高于“全画面都清楚”。合理的高光溢出、深暗、近黑阴影与剪影可以保留；只修复与选定光位、曝光和相机动态范围不一致的断裂、脏灰与无来源亮暗。

## 曝光意图

每次在内部选择一个，不增加新的配方编号：

| 曝光意图 | 使用场景 | 暗部与高光策略 |
| --- | --- | --- |
| `source-matched` | 保持原片 | 保留原曝光层级，只修不连续和无来源异常 |
| `balanced` | 商业柔光、自然窗光 | 受光与背光都有层次，但不要求等亮 |
| `highlight-priority` | 夕阳、逆光、舞台亮源 | 优先保住太阳、轮廓与亮源关系；主体背光面可深暗 |
| `shadow-priority` | 暗室环境中明确要求看清主体 | 优先保留主体暗部；可接受灯具、窗外等亮源自然溢出 |
| `low-key` | 电影低调、暗调写真、霓虹 | 大面积阴影可接近黑色，只保留必要轮廓或局部受光 |
| `silhouette` | 明确剪影、强逆光 | 无正面补光；主体内部细节可消失，以外轮廓和姿态为主 |
| `high-key` | 电商、极简商业 | 高亮但有柔和层次，避免整体灰平 |

不要把 `clean shadow` 理解为浅阴影；它表示色彩和边缘干净，没有脏灰、噪点与无来源局部加深。

| 商业影棚柔光 | `L3 + Sx + T1 + A0` |
| 暗调斜照一道光 | `L7 + Sx + T0/T2 + A0/A5` |
| 经典时尚杂志 | `L8 + Sx + T1 + A0` |
| 电影低调冷暖 | `L9 + Sx + T3 + A0/A5` |

## 主光配方 L0–L12

### L0 — 匹配原片

用途：用户没有指定新光线，只修复平光、无来源死黑、异常高光或割裂。

提示句：

```text
保持原主光方向、曝光层级与现场明暗，只修复不连续过渡、无来源亮暗和平光；不自动抬起原本合理的深暗或压低合理亮源。
```

### L1 — 自然逆光修复

提示句：

```text
保留后侧亮源、发丝轮廓和背景曝光，默认采用高光优先：面部背光侧可明显压暗或形成局部剪影；只有明确要求补面时才加入低强度环境反射，无抠图白边或新增眼神光。
```

### L2 — 柔和窗边自然光

提示句：

```text
从指定侧前上方加入大面积柔窗光，形成宽缓明暗渐变；按环境反射决定暗侧深度，必要时才用微弱 Fill，人物、衣物和墙面按同方向衰减。
```

### L3 — 商业大型柔光

提示句：

```text
左前或右前上方大型柔光为主光，正面低强度补光；鼻影短柔、眼窝清楚、面颊与下颌层次自然，背景低幅响应。
```

### L4 — 户外天空柔光

提示句：

```text
用宽广天空柔光与现场反射照亮人物，保留低幅面部曲率和自然环境色；不添加棚拍热点或过强发丝描边。
```

### L5 — 室内实景混合光

提示句：

```text
让可见暖色灯具只照亮合理邻近区域，远离灯具处自然衰减并可进入深暗；只有现场存在中性环境光时才保留低幅 Fill，人物与房间明暗相互对应。
```

### L6 — 单点硬光

提示句：

```text
用指定方向的小面积硬光形成清楚且符合曲率的阴影边缘；受光面可出现受控高光溢出，背光面可形成深影或近黑遮挡，鼻影、颈影、衣物与背景投影同向。
```

### L7 — 暗调斜向光带

提示句：

```text
采用低调曝光，让边缘略柔的斜向窄光带穿过眼、鼻梁和面颊并沿曲率连续变化；光带外可大面积接近黑色，只保留必要轮廓，邻近背景同向响应。
```

### L8 — 经典杂志伦勃朗光

提示句：

```text
侧前上方大型柔光塑造克制伦勃朗光，细微正面补光保留眼窝；一侧面颊阴影深而柔，只保留一处同源眼神光。
```

### L9 — 电影低调冷暖

提示句：

```text
暖色侧主光塑造强烈明暗面，采用低调曝光且默认无正面补光；背光侧可接近黑色，冷色环境光只落在背景与轮廓。
```

### L10 — 黄金时刻夕阳侧逆光

提示句：

```text
暖色夕阳从侧后方照亮发丝和肩部，采用夕阳高光优先曝光且默认无正面补光；面部背光侧自然深暗或形成局部剪影，受光边缘可轻微溢出，背景同步出现斜射暖光与长阴影。
```

### L11 — 赛博朋克双色霓虹

提示句：

```text
青色轮廓光与另一侧洋红主光方向分明、主次清楚，采用低调曝光且不加无来源白色补光；未受光区域可深暗，不做全脸高饱和染色。
```

### L12 — 商业极简均匀柔光

提示句：

```text
顶前方大型柔光形成均匀漫反射，轻微正面填充消除死角；高光洁净、阴影柔和，适合美妆与极简商业画面。
```

## 氛围配方 A0–A6

氛围不是第二主光。默认 A0；只有用户要求或场景确实适合时选择 A1–A6 中一个。A1–A5 服从主光；A6 是特殊强制覆盖项。

### A0 — 无附加氛围

```text
不新增窗影、树影、Bokeh、镜头光晕或体积光。
```

### A1 — 柔软窗影

```text
一层低对比柔窗影跨过人物与邻近墙面，透视、方向和边缘软硬服从主光，不像矩形贴纸。
```

### A2 — 自然树影

```text
稀疏树叶投影随面部与衣物曲率轻柔断续，允许按真实落点跨过局部眼睛与面颊，邻近背景出现同方向响应；阴影保持干净，不形成无来源脏斑。
```

### A3 — 柔焦光斑 Bokeh

```text
少量柔焦光斑只存在于景深允许的背景离焦区，颜色来自现场光源，不覆盖眼睛、皮肤或人物轮廓。
```

### A4 — 夕阳镜头光晕

```text
沿夕阳入射方向保留一处轻柔镜头光晕；靠近亮源处可降低局部对比并轻微溢出，但不能脱离主光方向覆盖全画面。
```

### A5 — 轻微体积光与微尘

```text
只有在光源方向明确时加入极轻的体积光和稀疏微尘，集中在空气与背景，不以烟雾遮盖人物。
```

### A6 — 主体全黑逆光剪影

选择即强制执行，不受其他 L/S 配方的正面受光或肤质要求抵消：

```text
把人物置于明亮背景或背后主光之前，采用纯剪影曝光并取消全部正面与侧面补光、眼神光和人物内部受光；脸、皮肤、头发、衣物及身体内部统一落为干净连续的全黑，不显示五官、肤色、发丝、衣纹或饰品细节，只以原头发/头部外轮廓、头身比例和姿态形成清楚剪影；背景按主光与色温正常曝光，可有极窄同源轮廓溢光但不得照亮人物内部。
```

A6 覆盖规则：

- 强制 `exposure_intent: silhouette`、`fill_policy: none`、`shadow_policy: silhouette`；
- L 只保留背景光源的方向、软硬与环境风格，任何照亮人物正面或侧面的句子都删除；
- S 仍可记录编号，但不把毛孔、唇纹、眼周或肤色写入实际提示；
- T 只控制背景、亮源和轮廓附近光色，不给黑色人物内部着色；
- 人物内部出现可辨五官、肤色、眼神光、发丝高光、衣纹或饰品明暗即为 A6 失败。

## 皮肤配方 S0–S2

### S0 — 小脸/远景

适用：面部高度 `<256 px`。

```text
保持干净连续肤色与自然反射，去除塑料般均匀感；不新增可见毛孔、黑头、绒毛、痣或细纹。
```

### S1 — 中景默认

适用：面部高度 `256–511 px`，也是不确定时的默认方案。

```text
白皙健康、干净连续，恢复低对比不规则微纹理、原有唇纹与眼周层次和克制额头反光；不新增黑点、粉屑或色斑。
```

### S2 — 高分辨率近景

适用：面部高度 `≥512 px`。

```text
恢复干净真实的相机微纹理：脸颊孔理柔和、鼻头略清晰，保留原有唇纹、眼下浅纹、细绒毛和标志；上胸与锁骨保持同肤色连续性。
```

S2 也不能主动添加大片黑头、卡粉、浮粉、粉屑、干裂或醒目痣。源图已有内容可以保留，但不强化。

所有 S 配方只要求有效受光区域呈现相应微纹理。处于深暗或剪影中的皮肤服从曝光，不强行恢复与亮面同等的毛孔、唇纹或眼周细节。

选择 A6 时所有 S 配方的可见纹理要求暂停；黑色人物内部不显示任何皮肤细节，也不以“恢复真实肤质”为理由补亮。

## 色温配方 T0–T4

### T0 — 保持源图白平衡

```text
保持原白平衡和肤色中性点，只修复局部不连续色偏。
```

### T1 — 中性日光

```text
主光为中性自然日光，皮肤白皙健康，白色物体接近中性，不泛蓝或发黄。
```

### T2 — 黄金暖光

```text
暖色只集中在夕阳或灯光的受光面与邻近反射，肤色中性区仍健康，不做整图橙色滤镜。
```

### T3 — 暖主光与冷环境

```text
暖色主光照亮主体，冷色只留在背景与轮廓，过渡宽缓，皮肤不出现橙黄/青灰断层。
```

### T4 — 青洋红霓虹

```text
青与洋红光各有明确方向和主次，有效受光区域保持自然皮肤反射，未受光区域可深暗，饱和度受控。
```

## 可选控制词

这些词只在需要时加入，不能全部堆叠：

| 目标 | 精确用法 |
| --- | --- |
| 眼睛更有神 | `single source-consistent catchlight in eyes`，只保留一处同源眼神光 |
| 恢复非预期暗部丢失 | `subtle fill light, retained shadow detail`，仅用于 balanced/source-matched |
| 柔和 | `large diffused key light, broad shadow transition` |
| 硬朗 | `hard single-point key light, clean shadow edge` |
| 接触深度 | `very subtle ambient occlusion at contact areas`，不能当补光 |
| 胶片感 | `very fine uniform film grain across the frame`，仅用户明确要求时使用 |
| 干净阴影 | `clean shadow, no muddy gray patches` |
| 平衡曝光 | `balanced exposure, retained highlight and shadow detail` |
| 高光优先 | `expose for the sunset highlights, naturally deep backlit shadows` |
| 阴影优先 | `expose for the subject shadows, allow practical highlights to bloom naturally` |
| 剪影 | `no frontal fill, clean readable outer silhouette, interior detail falls to black` |
| A6 全黑主体 | `full black backlit subject silhouette, no facial or clothing detail, no catchlight or fill, preserve the exact outer contour and pose` |
| 低调曝光 | `low-key exposure, deep clean shadows, sparse controlled highlights` |

## 六套导演公式

### 经典时尚/杂志

```text
L8 + S1/S2 + T1 + A0
侧前上方大型柔光；细微补光；一侧面颊深柔阴影；单一眼神光；可选全画面极轻胶片颗粒。
```

### 戏剧化/电影感

```text
L9 + S1 + T3 + A0/A5
暖色侧主光；低调曝光；默认无正面补光；冷色背景与轮廓；深暗可接近黑色；最多一种轻微体积氛围。
```

### 商业电商/极简

```text
L12 + S1/S2 + T1 + A0
顶前大型柔光；均匀漫反射；洁净高光；柔和阴影；无额外氛围。
```

### 自然日落逆光

```text
L10 + S1/S2 + T2 + A4
暖色侧后夕阳；高光优先或剪影曝光；默认无正面补光；发丝轮廓、面部背光深影、背景长阴影与单一光晕。
```

### 赛博朋克/霓虹

```text
L11 + S1/S2 + T4 + A3
青色轮廓；洋红主光；低调曝光；未受光面深暗；Bokeh 只在离焦背景。
```

### 主体全黑逆光剪影

```text
Lx + Sx + Tx + A6
A6 强制改为纯剪影曝光；背后光源或亮背景；无 Fill、无眼神光、无人物内部受光；完整人物内部全黑，只保留原外轮廓、比例与姿态。
```

## 冲突处理

- 皮肤粗糙：删除 `film grain`、强对比、深邃面颊和全部瑕疵枚举，回到 S1；
- 结果无变化：加强 L 的方向与落点，不增加身份同义约束；
- 光线混乱：改为 `Lx + A0`，只留一个主光和一个 Fill；
- 非预期暗部丢失：仅当曝光意图为 balanced/source-matched 时增加 subtle fill；low-key、highlight-priority 或 silhouette 不补亮；
- A6 不够黑：删除 L 中全部人物正面/侧面受光、Fill、catchlight 和 S 纹理句，明确“整个人物内部连续全黑”；
- 光影像贴纸：要求同一光跨过面部、衣物和邻近背景，并删除第二氛围；
- 肤色脏乱：保持 T0/T1，删除橙青分色与局部色差描述。
